# Бот техподдержки

Telegram бот с системой тикетов для технической поддержки.

## Функционал

### Для пользователей:
- Создание тикетов
- Просмотр своих тикетов
- Получение ответов от поддержки

### Для администраторов:
- Просмотр всех тикетов
- Изменение статусов тикетов
- Ответы на тикеты
- Админ панель

## Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

3. Отредактируйте `.env`:
- `TELEGRAM_TOKEN` - токен вашего бота от @BotFather
- `ADMIN_IDS` - ID администраторов через запятую
- `DATABASE_URL` - путь к базе данных (по умолчанию SQLite)

4. Запустите бота:
```bash
python bot.py
```

## Как получить токен бота

1. Найдите @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в `.env` файл

## Структура базы данных

- **Users** - пользователи бота
- **Tickets** - тикеты поддержки
- **Messages** - сообщения в тикетах

## Использование

### Пользователи:
1. Нажмите `/start`
2. Выберите "Создать тикет"
3. Введите заголовок и описание проблемы
4. Ждите ответа от администратора

### Администраторы:
1. Нажмите `/start`
2. Выберите "Админ панель"
3. Просматривайте тикеты и отвечайте на них
