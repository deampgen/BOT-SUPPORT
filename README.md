# 🤖 Telegram Moderator Bot

[![Python Version](https://img.shields.io/badge/python-3.8+-blue.svg)](https://python.org)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![Telegram](https://img.shields.io/badge/telegram-bot-blue.svg)](https://t.me)

> Комплексный бот-модератор для Telegram групп с функциями парсинга, AI-анализа токсичности и отслеживания активности пользователей.

## ✨ Возможности

### 📊 Ежедневный парсинг чата
- 🔍 Автоматический сбор истории сообщений
- 📁 Экспорт в Excel с полной информацией:
  - ID сообщения, ID пользователя, никнейм
  - Текст сообщения с сохранением эмодзи
  - Название чата, дата и время
- 📤 Автоматическая отправка отчета админам

### 🧪 AI-анализ токсичности
- 🤖 Интеграция с OpenAI GPT для анализа сообщений
- ⚠️ Выявление оскорблений, угроз, спама
- 📈 Ежедневный отчет с токсичными сообщениями
- 📊 Статистика уровня токсичности чата

### 💬 Авто-комментирование правил
- 📝 Автоматическое добавление правил чата
- 🎯 Под постами администратора
- ⚡ Мгновенная реакция на новый контент

### 👥 Отслеживание активности пользователей
- 📅 Дата вступления в группу
- 💬 Дата последнего сообщения
- 🔢 Количество сообщений за разные периоды
- 🏷️ Статусы: active/inactive/left
- 🔄 Ежедневное обновление данных

### 📈 Интеграция с Google Sheets
- 📊 Автоматическая выгрузка данных в таблицы
- ⏰ Отслеживание активности в реальном времени
- 🎨 Цветовая индикация статусов

### 📅 Недельные отчеты
- 📋 Автоматические отчеты по неактивным пользователям
- 📤 Отправка по пятницам
- 📊 Детальная статистика

## � Быстрый старт

### 📥 Установка
```bash
# Клонируйте репозиторий
git clone https://github.com/deampgen/telegram-moderator-bot.git
cd telegram-moderator-bot

# Установите зависимости
pip install -r requirements.txt
```

### ⚙️ Настройка

#### 🤖 1. Создание Telegram бота
1. Найдите [@BotFather](https://t.me/botfather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Сохраните токен бота

#### 🔧 2. Настройка переменных окружения
Скопируйте `.env.example` в `.env` и заполните данными:

```bash
cp .env.example .env
```

**Обязательные параметры:**
- `BOT_TOKEN` - токен вашего Telegram бота
- `ADMIN_USER_ID` - ваш ID в Telegram
- `ADMIN_CHAT_ID` - ID админского чата/канала
- `TARGET_GROUP_ID` - ID группы для модерации
- `OPENAI_API_KEY` - API ключ OpenAI

#### 📊 3. Настройка Google Sheets (опционально)
1. Создайте проект в [Google Cloud Console](https://console.cloud.google.com/)
2. Включите Google Sheets API и Google Drive API
3. Создайте сервисный аккаунт
4. Скачайте файл ключей `credentials.json`
5. Создайте новую Google Таблицу
6. Поделитесь таблицей с сервисным аккаунтом

#### 🚀 4. Запуск бота
```bash
python main.py
```

## ⏰ Автоматические задачи

Бот автоматически выполняет следующие задачи:
- **📅 Ежедневно в 09:00** - Парсинг чата и анализ токсичности
- **🔄 Каждые 6 часов** - Обновление Google Sheets
- **📊 По пятницам в 16:00** - Недельный отчет по неактивным пользователям

## 📊 Структура данных

### 🗄️ База данных SQLite
- `messages` - Все сообщения чата
- `users` - Информация о пользователях
- `daily_activity` - Ежедневная активность
- `toxic_reports` - Отчеты о токсичности

### 📈 Google Sheets
- `User Activity YYYY-MM` - Активность пользователей за месяц
- `Daily Reports` - Ежедневные отчеты
- `Inactive Users Tracking` - Отслеживание неактивных пользователей

## 🔧 Конфигурация

Основные настройки в `config.py`:
- `DAILY_PARSE_TIME` - Время ежедневного парсинга
- `WEEKLY_REPORT_TIME` - Время недельного отчета
- `CHAT_RULES` - Текст правил чата
- `TOXICITY_PROMPT` - Промпт для анализа токсичности

## � Устранение проблем

### Частые проблемы:
1. **🤖 Бот не отвечает на команды**
   - Проверьте правильность токена
   - Убедитесь, что вы добавлены в ADMIN_USER_ID

2. **🧠 Ошибка OpenAI API**
   - Проверьте правильность API ключа
   - Убедитесь, что у вас есть достаточный баланс

3. **📊 Проблемы с Google Sheets**
   - Проверьте правильность файла credentials.json
   - Убедитесь, что таблица доступна для сервисного аккаунта
